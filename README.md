# Simple Sales Dashboard

## Objective

This project focuses on building an interactive sales dashboard to analyze business performance across regions, product categories, and time periods. The dashboard provides a clear visual representation of key sales metrics, helping users identify trends and make informed decisions.

## Dataset

**Dataset:** Superstore Sales Dataset

**Attributes Used:**

* Order Date
* Region
* Category
* Sales
* Profit

## Tools Used

* Power BI Desktop
* Microsoft Excel
* Python (Pandas)
* DAX (Data Analysis Expressions)

## Project Features

* Interactive KPI cards displaying Total Sales, Profit, Orders, and Profit Margin.
* Monthly sales trend analysis using a line chart.
* Regional sales comparison through a bar chart.
* Category-wise sales distribution using a donut chart.
* Dynamic region filtering with slicers.
* Visual highlighting of top-performing regions and categories.

## Key Insights

* The West region recorded the highest overall sales.
* Technology emerged as the leading product category by revenue.
* Sales exhibited a steady growth pattern with peak performance during 2016 and 2017.
* A profit margin of 46.02% indicates strong business profitability.

## Outcome

The dashboard successfully transforms raw sales data into meaningful visual insights. It enables quick performance evaluation, trend identification, and comparative analysis, making business reporting more effective and accessible.
